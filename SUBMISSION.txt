PROJECT SUMMARY:

Neon Dodge is a browser-based neon arcade survival game developed as the final capstone project for the EdVyro Game Development Internship.

The player must survive for 60 seconds while avoiding falling obstacles, earning score, and progressing through five increasing difficulty levels.


FINAL FEATURES:

- 60-second survival gameplay
- Five-level difficulty progression
- Start, Playing, Paused, Won, and Lost game states
- Score and best-score persistence using localStorage
- Pause and restart functionality
- Keyboard controls
- Mobile touch controls
- Audio feedback and sound toggle
- Reduced-motion accessibility option
- Visible keyboard focus
- Screen-reader live status
- Responsive mobile-friendly interface
- Visual feedback for game events
- Final credits and project information
- Published production build on Vercel

PLAYTESTING:

The game was tested by three participants using the same five playtest questions.

Overall results:
- All participants understood the main objective.
- Controls were generally easy to discover and use.
- No major confusion was reported.
- Feedback highlighted the need for more satisfying audio effects.
- Additional suggestions included increased difficulty and improved colour grading.

The strongest recurring feedback was to improve and expand satisfying sound effects.
