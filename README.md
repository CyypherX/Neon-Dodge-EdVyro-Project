# NEON DODGE — EdVyro Task 02

A small original arcade game prototype created for the **Game Design Document and Playable Prototype** task.

## What is included
- `index.html` — game structure and UI
- `style.css` — responsive neon interface
- `script.js` — complete gameplay logic
- `GDD.md` — one-page game design document
- `README.md` — project documentation

## How to run
No build tools are required.

### Option 1 — Open locally
Open `index.html` in a modern browser.

### Option 2 — VS Code
Open the project folder in VS Code and use Live Server.

### Option 3 — Vercel
Import the repository into Vercel. The project is static and requires no build command.

## Gameplay
Survive for 60 seconds while avoiding incoming obstacles.

### Controls
- Left Arrow / A: move left
- Right Arrow / D: move right
- Space: start/restart
- Mobile: use the on-screen arrow buttons

## Suggested repository name
`neon-dodge-edvyro-task-02`

## Suggested public project description
> Neon Dodge is a browser-based arcade survival prototype created for EdVyro Task 02. The player moves horizontally to avoid falling obstacles, with increasing difficulty, score tracking, a 60-second survival target, restart flow, and responsive mobile controls.
